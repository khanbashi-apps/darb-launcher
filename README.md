# درب · Darb

لانشر عربي لشاشات السيارات التي تعمل بنظام أندرويد (شاشات 7 بوصة فما فوق).

## الإصدار 0.1

- شاشة رئيسية: عداد سرعة من GPS، مسافة الرحلة، اختصارات الطريق (خريطة، أقرب محطة وقود، أقرب مسجد، البيت).
- مكتبة القرآن الكريم من [mp3quran.net](https://mp3quran.net/ar/api):
  - **القراء**: اختيار القارئ ثم الرواية ثم السورة، مع تشغيل متتابع للسور.
  - **السور**: اختيار السورة ثم القارئ.
  - **الإذاعات** مقسمة إلى: القراء، التفسير وعلوم القرآن، ترجمة معاني القرآن الكريم، السيرة والقصص، تلاوات متميزة، الرقية الشرعية، الفتاوى، الأدعية والأذكار، القراءات العشر، مواسم الخير، السنة النبوية، إذاعة القرآن الكريم - السعودية.
- كل التطبيقات المثبتة مع البحث.
- شريط سفلي: الرئيسية، القرآن، الخرائط، التطبيقات، إعدادات الجهاز.

## التثبيت

1. من تبويب **Actions** افتح آخر بناء ناجح، ونزّل ملف `darb-debug-apk`.
2. ثبّت ملف APK على شاشة السيارة.
3. اضغط زر الرئيسية (Home) واختر **درب** ثم **دائماً** ليصبح الشاشة الرئيسية.

## التطوير

- Kotlin + Jetpack Compose، أقل إصدار أندرويد 8.0 (API 26).
- البناء: `./gradlew assembleDebug`
